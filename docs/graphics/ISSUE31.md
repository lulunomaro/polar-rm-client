# Endfield 启动卡顿与 PR #28 集成验收（2026-10-31）

本轮在 PR #28 内整合 `main@7362475` 的 UI 双向切换，以及此前只合入
`hjq@4e1e182` 的 PR #30 设置修复。最终功能提交为 `f5e0362`。
没有修改液态玻璃 shader、材质、动画曲线或裁判 wire 格式。

## 已定位与修复

- 启动阶段的字库预热虽每次只处理一个字体，但每个字体一次测量并绘制上千
  字符。实际桌面 trace 捕获了约 245ms 的单次预热回调，阻塞主线程。
  现在按 16 个字符分片测量/栅格化；整行 shaping 按 8 行分片。每轮仍使用
  原来的 3ms 软预算，Qt/驱动单个操作不能强行抢占，记录实际耗时。
- 分片之间不保留活动 QPainter 或未发布的 GL 纹理；页面完整后才发布。
  绘制请求若更新同一字库，预热会重新合并，不能用旧页面覆盖新字形。
  保留字体、度量、字形排序、行页划分、纹理过滤和缓存上限，未降低字数或画质。
- 合并两条分支的原生代码后重新构建 DLL，包含 UI 切换动作 21、显卡选择及
  呈现节奏；不能在两个旧 DLL 中任选一个。新版本为
  `build_577e1dac55353350`，SHA-256
  `b606ee7882cabb4d1a7a77863fc38eac4e7c9780bef503716692e994d05fdea2`。
  54 个完整运行资源通过清单校验，保留用户私有素材。
- 显卡诊断和说明改为可换行，设备选择按有限内容宽度布局，修复小窗口设置页
  被长设备名/诊断撑大的问题。PR #30 的下拉首帧、分类首击和圆角修复一并保留。
- 后端回归查出 Hero 部署状态投影后丢失了视频源切换。恢复权威状态到源选择
  的连接；部署期间 Auto/UDP 请求也只能返回 Native，断流为空，不回退普通图传；
  退出同步后恢复保存的普通源。没有解锁控制或发送运动/开火命令。
- 准星页保留平滑滚动。旧测试只泵事件而不推进动画时间，现等待原动画结束后，
  同时断言滚动位置和目标控件完整可见，不删断言或改成瞬间滚动。
